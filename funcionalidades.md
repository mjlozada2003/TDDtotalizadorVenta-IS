# Funcionalidades desde la perspectiva del usuario PRIMERA PARTE
1. Debe poder ingresar la cantidad de items(ESTO NO)
1. Debe pode error un mensaje de error cuando la cantidad de items sea invalida o cero
2. Debe poder ingresar el precio por item (esto no)
3. Debe poder elegir el código de estado de una lista desplegable para evitar errores
4. Debe poder ver su descuento
5. Debe poder ver sus impuestos
6. Debe poder ver el precio total con descuentos e impuestos
7. Debe poder ver el precio total neto (sin descuento ni impuesto)
8. Cancelar compra
9. Quiero poder ver un mensaje de error cuando se ingresen precios negativos o informacion erronea
10. Como usuario quiero poder confirmar mi compra
